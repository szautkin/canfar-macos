# Keyboard shortcuts and menus

Every menu of Verbinal, and every keyboard shortcut, by where it works. The menus Verbinal shares with
every Mac app (Edit, Window) work as usual.

## Menus

### Verbinal

| Item | Shortcut | What it does |
|---|---|---|
| **About Verbinal** | | The version, and the details for a bug report |
| **Settings…** | ⌘, | [Settings](14-settings.md) |
| **Quit Verbinal** | ⌘Q | |

### File

| Item | Shortcut | What it does |
|---|---|---|
| **Export All…** | ⇧⌘E | [Export Data](03-research.md#exporting-everything): your observations, notes and searches as a bundle |

## Shortcuts by screen

### Everywhere

| Shortcut | What it does |
|---|---|
| ⌘B | Show or hide the file browser |
| ⌘, | Settings |
| Esc | Close a dialog; close every hint an assistant put up |

### Search

| Shortcut | What it does |
|---|---|
| ⌘↩ | Search |
| ⇧⌘↩ | Execute the ADQL query |
| ⌘F | Filter the results by a column |
| ⌘[ and ⌘] | Previous and next page of results |
| ⇧⌘E | The results' **Export** menu (also **File ▸ Export All…**) |

### Research

| Shortcut | What it does |
|---|---|
| ⌘O | Open the selected observation's file |
| ⇧⌘R | Reveal it in the Finder |
| ⌘⌫ | Delete the observation |

### FITS Viewer

| Shortcut | What it does |
|---|---|
| ⌘T | New tab |
| ⌘W | Close the tab |
| ⇧⌘L | Search the archive at the crosshair |
| ⇧⌘B | Blink |
| Space, ←, → | During blink: pause, image A, image B |
| Esc | Clear the crosshair; stop blinking |

### Cube Viewer

| Key | What it does |
|---|---|
| ← and → | Previous and next channel (with Shift: ten) |
| Space | Play or pause the channels |
| V | Switch between Slice and Volume |
| R | Reset the window |

### Storage

| Shortcut | What it does |
|---|---|
| ⌘R | Refresh the folder |
| ⇧⌘N | New folder |
| ⌘⌫ | Delete the selected item |

### Portal and Image Discovery

| Shortcut | What it does |
|---|---|
| ⌘R | Refresh the batch jobs, or a probe's logs |
| ⌘⌫ | Clear every package filter |
| ⇧⌘C | Copy a probe's failure, or an image's manifest |
| ↩ | **Use This Image** |

### Remote Compute and the AI Guide

| Shortcut | What it does |
|---|---|
| ⌘↩ | Run the code (Remote Compute); save a tool description (AI Guide) |

### First launch

| Shortcut | What it does |
|---|---|
| ⌘Q | **Quit** instead of accepting the Terms of Use |
