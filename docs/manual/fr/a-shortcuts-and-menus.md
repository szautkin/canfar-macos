# Raccourcis clavier et menus

Chaque menu de Verbinal, et chaque raccourci clavier, selon l’endroit où il fonctionne. Les menus que
Verbinal partage avec toutes les apps Mac (Édition, Fenêtre) fonctionnent comme d’habitude.

## Menus

### Verbinal

| Élément | Raccourci | Ce qu’il fait |
|---|---|---|
| **À propos de Verbinal** | | La version, et les détails pour un rapport de bogue |
| **Réglages…** | ⌘, | [Réglages](14-settings.md) |
| **Quitter Verbinal** | ⌘Q | |

### Fichier

| Élément | Raccourci | Ce qu’il fait |
|---|---|---|
| **Tout exporter…** | ⇧⌘E | [Exporter les données](03-research.md#tout-exporter) : vos observations, notes et recherches en un paquet |

## Raccourcis par écran

### Partout

| Raccourci | Ce qu’il fait |
|---|---|
| ⌘B | Afficher ou masquer le navigateur de fichiers |
| ⌘, | Réglages |
| Esc (Échap) | Fermer une fenêtre de dialogue ; fermer toutes les indications d’un assistant |

### Rechercher

| Raccourci | Ce qu’il fait |
|---|---|
| ⌘↩ | Rechercher |
| ⇧⌘↩ | Exécuter la requête ADQL |
| ⌘F | Filtrer les résultats selon une colonne |
| ⌘[ et ⌘] | Page de résultats précédente et suivante |
| ⇧⌘E | Le menu **Exporter** des résultats (aussi **Fichier ▸ Tout exporter…**) |

### Recherche

| Raccourci | Ce qu’il fait |
|---|---|
| ⌘O | Ouvrir le fichier de l’observation sélectionnée |
| ⇧⌘R | L’afficher dans le Finder |
| ⌘⌫ | Supprimer l’observation |

### Visionneuse FITS

| Raccourci | Ce qu’il fait |
|---|---|
| ⌘T | Nouvel onglet |
| ⌘W | Fermer l’onglet |
| ⇧⌘L | Chercher dans l’archive au réticule |
| ⇧⌘B | Blink |
| Espace, ←, → | Pendant le blink : pause, image A, image B |
| Esc (Échap) | Retirer le réticule ; arrêter le blink |

### Visionneuse Cube

| Touche | Ce qu’elle fait |
|---|---|
| ← et → | Canal précédent et suivant (avec Maj : dix) |
| Espace | Lancer ou mettre en pause le défilement des canaux |
| V | Passer de Slice à Volume |
| R | Réinitialiser la fenêtre |

### Stockage

| Raccourci | Ce qu’il fait |
|---|---|
| ⌘R | Actualiser le dossier |
| ⇧⌘N | Nouveau dossier |
| ⌘⌫ | Supprimer l’élément sélectionné |

### Portail et Découverte d’images

| Raccourci | Ce qu’il fait |
|---|---|
| ⌘R | Actualiser les tâches en lot, ou les journaux d’une sonde |
| ⌘⌫ | Effacer tous les filtres de paquets |
| ⇧⌘C | Copier l’échec d’une sonde, ou le manifeste d’une image |
| ↩ | **Utiliser cette image** |

### Calcul à distance et Guide IA

| Raccourci | Ce qu’il fait |
|---|---|
| ⌘↩ | Exécuter le code (Calcul à distance) ; enregistrer une description d’outil (Guide IA) |

### Premier lancement

| Raccourci | Ce qu’il fait |
|---|---|
| ⌘Q | **Quitter** au lieu d’accepter les conditions d’utilisation |
