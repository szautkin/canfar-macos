# Manuel de l’utilisateur de Verbinal

Verbinal est une app Mac pour les astronomes qui travaillent avec le Centre canadien de données
astronomiques (CADC) et la plateforme scientifique CANFAR. Elle cherche dans l’archive, garde vos
observations et vos notes, affiche les images FITS, les spectres et les cubes de données, gère votre
stockage VOSpace, et lance sessions, tâches en lot et code sur CANFAR, le tout dans une seule fenêtre. Un
assistant IA peut y travailler avec vous, selon vos conditions.

Ce manuel couvre Verbinal 1.4, sous macOS 14 ou plus récent. [English version](../en/00-contents.md).

## Comment lire ce manuel

- Les mots en **gras** sont ce que vous voyez à l’écran : un bouton, un champ, un onglet. Ils sont écrits
  comme l’app les écrit, y compris les quelques-uns qu’elle laisse en anglais.
- **Réglages ▸ Agent IA** signifie : ouvrez les Réglages, puis leur section Agent IA.
- ⌘ est la touche Commande, ⇧ Majuscule, ⌥ Option, ⌃ Contrôle, ↩ Retour, ⌫ Supprimer.
- Les numéros sur une image correspondent à la liste numérotée qui la suit.
- Chaque chapitre se termine par ce qu’un assistant IA peut y faire, pour quand vous travaillez avec un.
- Les images montrent Verbinal en mode sombre ; en mode clair, les écrans sont les mêmes.

Commencez par [Premiers pas](01-getting-started.md). Si vous voulez seulement regarder un fichier FITS,
ouvrez la [Visionneuse FITS](04-fits-viewer.md) : aucun compte n’est nécessaire.
