# Verbinal for macOS · User manual · Manuel de l’utilisateur

The manual for **Verbinal 1.4 for macOS**, the Mac app for the Canadian Astronomy Data Centre (CADC) and
the CANFAR science platform: archive search, FITS and cube viewers, VOSpace storage, sessions and batch
jobs, Remote Compute, and working with an AI assistant.

Le manuel de **Verbinal 1.4 pour macOS**, l’app Mac du Centre canadien de données astronomiques (CADC) et
de la plateforme scientifique CANFAR : recherche dans l’archive, visionneuses FITS et de cubes, stockage
VOSpace, sessions et tâches en lot, calcul à distance, et travail avec un assistant IA.

- **[English](en/00-contents.md)**
- **[Français](fr/00-contents.md)**

Verbinal for macOS is free on the [Mac App Store](https://apps.apple.com/ca/app/verbinal/id6761290036). Its
source is on [GitHub](https://github.com/szautkin/canfar-macos).
